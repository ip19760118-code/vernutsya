## 1. Общий принцип

Приложение спроектировано так, чтобы все пользовательские данные оставались
на устройстве. У приложения нет учётных записей, регистрации, облачной
синхронизации и рекламы.

Разработчик не имеет доступа к вашим координатам, маршрутам, фотографиям,
заметкам и номеру телефона доверенного контакта.

## 2. Данные, которые обрабатываются только на устройстве

Эти данные создаются вами, хранятся в приватной папке приложения и
**никуда не передаются** — ни разработчику, ни третьим лицам.

| Данные | Зачем нужны |
|---|---|
| Точные координаты (GPS) | точка возврата, запись трека, расстояние и азимут до цели, позиция на карте, расчёт времени заката, магнитное склонение для поправки компаса |
| Трек прогулки (координаты и время) | навигация обратно, в том числе по пройденной тропе, сохранение маршрута |
| Точки маршрута, их названия и заметки | ориентирование, поиск урожайных мест |
| Фотографии точек | визуальная память о месте |
| Номер телефона доверенного контакта (SOS) | формирование текста SOS-сообщения |
| Настройки приложения | сохранение выбранных параметров |
| Загруженные статьи и фото справочника грибов | офлайн-доступ к справочнику |
| Скачанные области карт (тайлы) | офлайн-карта |

### 2.1 Как работает SOS

Приложение **не отправляет SMS самостоятельно** и не запрашивает разрешение
на отправку SMS. При нажатии кнопки SOS открывается системное приложение
сообщений с подготовленным текстом (координаты и ссылка на карту).
Отправку выполняете вы сами. Разработчик не видит ни номер, ни текст,
ни факт отправки.

### 2.2 Передача маршрутов

Кнопка «Отправить GPX» открывает системное меню «Поделиться». Файл маршрута
передаётся выбранному вами приложению только по вашему явному действию.
Дальнейшая обработка регулируется политикой этого приложения.

### 2.3 Точки и маршруты из других треков

При импорте точек из сохранённого или присланного маршрута фотографии
копируются в приватную папку приложения. Удаление импортированной точки
не затрагивает исходный маршрут.

## 3. Статистика использования (Яндекс AppMetrica)

Для понимания востребованности функций и контроля качества обновлений
приложение использует сервис мобильной аналитики **Яндекс AppMetrica**.
Обработчик: ООО «ЯНДЕКС», Российская Федерация. Данные обрабатываются
на серверах в России.

### 3.1 Что передаётся

- названия действий: `app_open`, `screen_view`, `track_started`,
  `track_finished`, `waypoint_added`, `waypoints_imported`, `follow_walk`,
  `target_changed`, `sos_received`, `gpx_import`, `gpx_share`, `share_app`,
  `update_check`, `update_open_store`, `open_store`;
- название экрана (например «Карта», «Справочник»);
- версия приложения;
- длина прогулки, округлённая до 10 метров, и длительность в минутах;
- признак сохранения маршрута («да»/«нет»);
- технические данные, собираемые SDK автоматически: модель устройства,
  версия ОС, язык, страна/город по IP-адресу, оператор связи,
  обезличенный идентификатор установки, сведения о сессиях и сбоях.

### 3.2 Что НЕ передаётся никогда

- координаты, трек, точки маршрута и их названия;
- фотографии и заметки;
- номер телефона доверенного контакта и текст SMS;
- содержимое файлов GPX;
- список установленных приложений, контакты, файлы устройства;
- скриншоты экрана.

Отслеживание геолокации в SDK **не включается**. Постоянный идентификатор
пользователя разработчиком не задаётся. Рекламные SDK в приложении
отсутствуют, показ рекламы не осуществляется.

### 3.3 Как отключить

**Настройки → Анонимная статистика → снять галочку «Помогать улучшать приложение».**
Передача данных прекращается сразу, настройка сохраняется между запусками.

### 3.4 Правовое основание и документы Яндекса

Обработка осуществляется на основании вашего согласия, которое выражается
оставленной включённой настройкой и может быть отозвано в любой момент
указанным способом (ст. 6, 9 ФЗ-152).

## 4. Прочие сетевые запросы

| Сервис | Что передаётся | Когда |
|---|---|---|
| Тайловые серверы OpenStreetMap | стандартный технический запрос (IP, User-Agent), координаты запрашиваемых тайлов | при просмотре карты и скачивании областей |
| `ru.wikipedia.org`, `upload.wikimedia.org` | название статьи о грибе | при загрузке статьи справочника по вашему нажатию |
| `api.github.com` | обезличенный запрос версии | при проверке обновлений |

Эти сервисы обрабатывают технические данные согласно собственным политикам.
Разработчик не получает от них ваших данных.

## 5. Разрешения и их назначение

| Разрешение | Зачем нужно | Можно ли отказать |
|---|---|---|
| `ACCESS_FINE_LOCATION`, `ACCESS_COARSE_LOCATION` | позиция, запись трека, навигация к точке возврата, поправка компаса | без него основная функция недоступна |
| `FOREGROUND_SERVICE`, `FOREGROUND_SERVICE_LOCATION` | запись трека при выключенном экране | без него трек прервётся при блокировке |
| `POST_NOTIFICATIONS` | уведомление с расстоянием до точки возврата | можно отказать, запись продолжится |
| `WAKE_LOCK` | предотвращение прерывания записи трека | без него возможны пропуски трека |
| `INTERNET`, `ACCESS_NETWORK_STATE` | карты, справочник, проверка версии, статистика | можно работать офлайн |

Приложение **не запрашивает** разрешений на отправку SMS, доступ к контактам,
микрофону, внешнему хранилищу, установку других приложений.

## 6. Хранение и удаление данных

- Пользовательские данные хранятся в приватной папке приложения под защитой
  стандартной изоляции Android.
- Отдельные точки, маршруты и статьи справочника удаляются внутри приложения.
- **Полное удаление локальных данных:** удалить приложение либо очистить его
  данные (Настройки Android → Приложения → Вернутся → Хранилище → Очистить данные).
- Для удаления данных аналитики обратитесь к обработчику (Яндекс) по ссылкам
  из п. 3.4 либо по адресу оператора из шапки документа.

## 7. Передача третьим лицам

Разработчик не продаёт и не раскрывает данные пользователей, кроме случаев:

1. обезличенная статистика — ООО «ЯНДЕКС» через AppMetrica (п. 3);
2. по вашему явному действию через меню «Поделиться» — выбранному вами приложению;
3. по обязательному к исполнению требованию уполномоченного органа в порядке,
   установленном законодательством РФ.

## 8. Дети

Приложение не предназначено для детей младше 12 лет и не собирает
целенаправленно данные детей. Возрастная маркировка — 12+ в связи с наличием
справочной информации о ядовитых грибах и рисках для здоровья.

## 9. Безопасность

- Данные защищены изоляцией приложений Android.
- Сетевые запросы выполняются по HTTPS.
- Приложение не содержит механизмов удалённого управления, скрытой загрузки
  исполняемого кода и обхода системных ограничений.
- Обновления устанавливает магазин RuStore.

## 10. Ваши права

Вы можете в любой момент:
- отключить статистику (п. 3.3);
- отозвать разрешения в настройках Android;
- удалить любые данные внутри приложения;
- удалить все локальные данные, удалив приложение;
- направить обращение по адресу из шапки документа.

Срок ответа — не более 30 календарных дней.
