## 🌲 О приложении

**«Вернутся»** помогает не потеряться в лесу. Поставьте точку у машины, идите за грибами — приложение пишет трек, а большая объёмная 3D‑стрелка всегда показывает направление обратно и расстояние по прямой.

Работает **без интернета**, **без Google‑сервисов** и **с заблокированным экраном** — расстояние до машины видно прямо в уведомлении.

## ✨ Возможности

| | |
|---|---|
| 🧭 **3D‑стрелка** | Объёмная стрелка + картинка цели на круге (домик, машина, палатка, гриб, флаг, звезда) |
| 📍 **Точки** | Точка возврата у машины + промежуточные точки; к любой можно вернуться |
| 🗺 **Офлайн‑карты** | Скачивание области при интернете и импорт `.mbtiles`; трек и точки поверх карты |

| 🔒 **Фон** | Запись трека с заблокированным экраном, уведомление с расстоянием и таймером |
| 🌗 **Два режима** | Простой (стрелка + 2 кнопки) и продвинутый (точки, карта, статистика) |
| 🔋 **ЭКО‑режим** | Реже опрашивает GPS — экономит батарею |

## 📥 Установка

1. Скачайте **[Vernutsya.apk](https://github.com/ip19760118-code/vernutsya/releases/download/v1.0/Vernutsya.apk)**.
2. Откройте файл на телефоне.
3. Разрешите **установку из неизвестных источников** (Android спросит).
4. Готово! Требуется **Android 8.0+**.

> ⚠️ Сборка отладочная, поэтому Android может показать предупреждение «неизвестное приложение» — это нормально, нажмите «Установить».

## 🚀 Быстрый старт

1. Встаньте у машины, дождитесь точности GPS **±10–15 м**.
2. Нажмите **«Отметить точку возврата»** — пойдёт запись трека.
3. Собирайте грибы 🍄 — по пути можно ставить промежуточные точки.
4. Решите вернуться — смотрите на стрелку и идите к машине.
5. Экран можно блокировать — запись продолжится.
6. В конце сохраните маршрут в GPX и отправьте друзьям.

## 🗺 Офлайн-карты

- **Скачать область:** откройте «Карта» → «Скачать», выберите детализацию — видимая область сохранится в «Мои карты» и будет доступна без интернета.
- **Импорт:** кнопка «Импорт» для готовых файлов `.mbtiles` (создаются в SAS.Planet, Mobile Atlas Creator, QMapShack).
